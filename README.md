# 摸鱼助手（moyu-electron-faceapi）

用于监控摄像头中的人脸，当检测到人数超过阈值时自动切换到安全页面，方便摸鱼。

## 技术栈

- **Electron**
- **face-api.js**: 人脸检测库
- **TensorFlow.js**: 机器学习库，face-api.js 的依赖

## 功能特性

- 📷 实时人脸检测
- ⚡ 低延迟，高性能
- 🛡️ 检测到他人时自动切换到安全页面
- ⌨️ 支持老板键（CommandOrControl+Shift+X）
- 📊 实时显示检测到的人数
- 🔧 可配置检测参数（间隔时间、人数阈值、最小人脸比例）
- 📝 详细的调试日志

## 安装和运行

### 前置要求

- Node.js (v16 或更高版本)
- pnpm (或 npm/yarn)

### 安装依赖

```bash
pnpm install
```

### 运行应用

```bash
pnpm start
```

### 打包应用

```bash
# 生成目录打包
pnpm run pack

# 生成安装包
pnpm run dist
```

## 配置说明

应用启动后，可以在界面上配置以下参数：

- **检测间隔 (ms)**: 每次检测的时间间隔，默认 500ms
- **人数阈值**: 触发切屏的人数阈值，默认 1 人
- **最小人脸高度比例 (%)**: 检测到的人脸最小高度占摄像头画面的比例，默认 8%
